# PICTURE editorial proposal

The owner approved Illustrated Cover, Field Plate and a separate Sprite Asset. Studio Product retains its existing base with optional Reflection control and Feature priority. The catalog counts and other recommendations below describe the proposal before this release.

## What I would change first

Give each starting hand a picture the player can recognize as successful. A cover needs a place to put a title. A product photograph needs to show the selling feature. A field plate needs to preserve the differences between specimens. Today the medium and mood are often vivid while those choices are left to chance.

I reviewed the 18 starting hands and the seven sections of the current catalog. Its 100 lineages have three grades each. The presets collectively equip 60 distinct lineages. That count measures coverage, not popularity. The findings below come from the catalog and its prompt composer. Image quality has not been tested.

## Grades, controls and exports

Start with the existing seven boards and slot budgets. Keep the single intensity control for the text pilot. A grade should strengthen one visible property while the subject, count, setting and camera remain stable unless the player changes their own cards.

| Proposed card | Grade 1 | Grade 2 | Grade 3 |
|---|---|---|---|
| Type-safe area | Keep fine detail away from the requested lettering zone. | Reserve that zone as one quiet value shape. | Keep silhouettes, hard edges and accents entirely outside the zone. |
| Reflection control | Put the brightest reflection away from the named feature. | Shape a broad highlight that describes the material and leaves the feature clear. | Separate the feature's contour from surrounding reflections throughout its length. |
| Matched views | Use the same orientation across the requested specimens. | Match orientation, scale and baseline. | Align corresponding landmarks across views while preserving observed differences. |
| Feature priority | Keep the named feature visible. | Give that feature the clearest edge in the image. | Concentrate local contrast and texture on the feature, simplifying competing detail around it. |

**One-off prompt.** The subject, supplied reference observations, fixed colors, placement and delivery dimensions belong to this job. Keep flags in the existing optional parameter tail. If the image needs room for a title, put the spatial instruction in the portable prompt so it survives when flags are disabled.

**Reusable skill.** Ask for the new subject, immutable features, intended use and any delivery dimensions. Carry forward the method of the hand. For Field Plate, retain “align comparable features at one scale.” Take the number and identity of specimens from the new brief. A grid size or palette becomes a reusable constraint only when the player deliberately locks it. The current skill exporter already leaves the subject out; a more specific hand procedure would give that separation practical value.

**First approval decision.** Pilot the four refits before merging any archetypes or hiding a card. Compare text on both briefs, remove one defining card at a time and check whether a reviewer can identify the lost instruction. If approved for a later image test, compare the same brief and model settings and inspect the actual contour, copy space, distinguishing feature or silhouette. Preserve saved IDs, work-in-progress prompts and style cards during any later migration.
